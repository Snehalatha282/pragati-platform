# Pragati - Women Career Re-Entry Empowerment Platform

## 🌟 Overview
Pragati is a web platform designed to empower women returning to work after career breaks. It provides personalized skill development, mentorship connections, job opportunities, and community support.

## 🚀 Features
- **User Authentication** - Secure login and registration
- **Skill Assessment** - AI-powered skill gap analysis
- **Personalized Learning** - Curated courses and learning paths
- **Mentorship** - Connect with industry mentors
- **Job Matching** - Find flexible job opportunities
- **Community Forum** - Share experiences and resources
- **Progress Tracking** - Monitor career comeback journey
- **Admin Dashboard** - Platform management

## 🛠️ Technology Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Flask (Python)
- **Database**: SQLite
- **AI/ML**: Scikit-learn (for recommendations)
- **Authentication**: Flask-Login / JWT
- **Visualization**: Chart.js
- **Version Control**: Git, GitHub
- **Deployment**: Render/Heroku/PythonAnywhere
